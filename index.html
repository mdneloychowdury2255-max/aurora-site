north · cold air · quiet code

Build small things that glow in the dark.

Northlight is a one-file studio for aurora gradients, canvas motion and interfaces that stay legible on a phone at 3am. No build step, no trackers, no framework — just the browser doing what it already does well.

Three habits

The constraints that keep this small.
01

One file, always

Everything ships in a single HTML document. If it needs a bundler, it needs a rethink.

02

Motion with a reason

Animation marks state and attention. Decoration that never stops moving gets deleted.

03

Legible first

Contrast, tap targets and line length are designed on a phone, then widened for desktop.
